**ST-ROTO 0.1.0 is the first public pre-release: AI-assisted and traditional rotoscoping inside Foundry Nuke.**

Click an object or draw a box around it on one frame and press **Track**. ST-ROTO tracks the object through the shot with SAM 2.1, running on your graphics card inside Nuke. You get **native, animated Nuke Roto shapes** that you can edit like any other shape, plus EXR mattes. Every AI feature can be switched off for traditional roto.

> ⚠ **Pre-release, not production-ready.** It is tested only on **Nuke 17.1 Non-commercial on Windows with an NVIDIA RTX GPU**, using synthetic test shots and public benchmark footage. It has not yet been used on a real production shot or tested on another computer. Please report problems and include the **System report** (ST-ROTO menu).

## Install

1. Close Nuke and put the downloaded files in **one folder**.
2. Double-click **`ST-ROTO-Setup.exe`**. The installer is not code-signed, so Windows SmartScreen may warn you: choose **More info → Run anyway**.
3. Type **1** and press Enter. The installer installs the main package and every model package in the folder, after checking every file's SHA-256 checksum.
   - It needs no administrator rights and downloads nothing.
   - Files go to `%LOCALAPPDATA%\ST-ROTO`, and a single marked block is added to `%USERPROFILE%\.nuke\init.py`.
4. Start Nuke and choose **Nodes → ST-ROTO → ST_Roto**. For a first check, open **ST-ROTO → System report…**.

Run the same installer later to **repair** (2), **roll back** (3) or **uninstall** (4). Uninstalling removes only ST-ROTO's files and its block in `init.py`.

**Requirements**
- **Windows:** Windows 10/11, 64-bit.
- **Nuke:** Nuke 17.1. Nuke 16 and 17.0 use the same Python 3.11 but are untested. Nuke 15 and older won't work with this package.
- **Graphics card:** an NVIDIA GPU with a recent driver (CUDA 12). Without one, tracking runs on the CPU and is slow. AMD and Intel GPUs are not supported yet.

## What it does

- **Prompts:** clicks, a box, or a rough mask (a Roto shape, another node's alpha, a mask file or Cryptomatte), for several objects per node.
- **Tracking:** Track, Re-track, Re-prompt here and Re-track flagged (with the large model). You can also re-track a frame range, exclude frames or lock frames. Your own keys are never overwritten.
- **Model choice:** *auto* picks the model by free GPU memory, with a CPU fallback.
- **Review:** "lost" and "check" flags appear in the status line, the Objects pane timeline and the viewer (magenta and yellow shapes).
- **Mattes:** multi-layer EXR mattes with guided-filter, ViTMatte or hard edges. Options include holdout and garbage roles, premultiplied or straight RGB, edge decontamination and despill, edge offset and blur, and core/edge layers.
- **Stereo and multi-camera:** one object per view, a disparity or epipolar search, and consistency checks.
- **CG plates:** extra channels pass through. Shapes can come straight from Cryptomatte, and hand keys can be propagated along motion vectors. Channel checks compare shapes with depth, vectors and Cryptomatte.
- **Exports:** JSON/SVG, Alembic, a RotoPaint copy, delivery packages and project packages.
- **Safety:** automatic backups and crash recovery.
- **Nodes and panes:** ST_RotoMatte and ST_RotoOutput nodes, an Objects pane, a Models pane (verify, self-test, versions and rollback), a System report, and presets.
- **Traditional roto:** possible with all AI switched off.

Full guide: `docs/USER_GUIDE_v0.md` (also installed with ST-ROTO).

## Known limits

- **Accuracy:** on SA-V benchmark footage (51 sequences) the mean IoU is 0.68 with the tiny model and 0.74 with the large model. Objects are sometimes lost; review the flags.
- **Nuke Non-commercial limits:** at most 10 Python-accessible nodes per session (save and reopen if you reach it) and renders up to 1920×1080. Larger plates are tracked from a reduced copy, with shapes kept at full resolution.
- **Hair and motion blur:** edges are limited. ViTMatte helps with hair.
- **Thresholds:** stereo, multi-camera and channel checks were tested on synthetic shots only, so their thresholds are provisional.
- **Collaboration:** a prototype only; there is no sharing between machines in the UI.
- **Installer:** the setup is not code-signed (DEF-009).
- **Status:** 1.0 criteria and their status: `docs/ACCEPTANCE.md`. Known defects: `DEFECTS.md`.
